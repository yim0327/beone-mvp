# BeONE 결정 기록

구현 전 미결 사항과 확정 결정을 기록합니다. 요구사항의 기준은 [PRD](PRD.md)입니다.

- 결론이 정해지기 전에는 `상태: 미결`로 두고, 담당자·기한·결론을 추측해 채우지 않습니다.
- 결정되면 결론, 근거(약관·자료 출처), 결정일을 적고 상태를 `확정`으로 바꿉니다.
- 미결 사항을 검증된 사실이나 이미 구현한 기능으로 표시하지 않습니다(PRD §11).

## 카드 규칙 조사 자료 (초안)

D-01~D-05의 근거와 시연용 4종 확정 내용은 [카드 4종 공식 근거 및 CODEF 매핑 조사](card-benefit-research.md)에 정리했습니다. D-02와 D-05의 사용자 확인 범위만 확정하고, 실제 카드의 공식 SKU·약관 버전 및 계산 세부 조건은 미결로 유지합니다.
