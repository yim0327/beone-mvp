- 조사 기준일: 2026-10-06
- 관련 요구사항: [PRD FR-01~FR-03](PRD.md), [미결 결정 D-01~D-05](decisions.md), [이슈 #5](https://github.com/yim0327/beone-mvp/issues/5)
- 상태: **시연용 4종 구성은 사용자 확인으로 확정(2026-10-08)**. 혜택 규칙은 공식 자료에 근거한 초안이며, 실제 보유카드의 공식 SKU·약관 버전 및 미확정 계산 조건은 `VERIFIED`로 표시하지 않는다.

## 2. 결정론적 룰 초안

모든 금액은 원 단위 정수로 모델링한다. 다만 **원 미만 할인금액의 절사/반올림 방법은 공식 근거 확인 전까지 미정**으로 둔다. 혜택 판정은 KB의 업종·가맹점 분류에 의존하므로, 이름만 비슷한 거래를 자동으로 대상 처리하지 않는다. 각 카드의 등록일·선택 서비스·브랜드·취소 접수일 등 필수 상태가 없으면 사용자 확인을 요청하고 해당 혜택을 `확인 필요`로 표시하며 확정 추천 계산에서 제외한다. 모르는 혜택을 0원 또는 확정 금액으로 대체하지 않는다(D-05, 2026-10-08 사용자 확인).

### 올라운드 티타늄카드 `09271`

- **기본 적립:** 국내외 가맹점 포인트리 1%, 전월 실적조건·적립한도 없음. 취소, 무이자할부, 대출, 세금·공과금, 관리비, 정부지원금, 등록금, 수수료·연회비, 상품권·선불카드 구입/충전 등은 적립 제외. 포인트리는 해당 이용분의 결제일 다음 영업일 적립, 취소 시 차감. [상품설명서 1·3쪽](https://img2.kbcard.com/obj/card/download/09271__prdctOpmn_20240417.pdf)
- **선택 할인:** `FUEL`(주유소·충전소, GS칼텍스 고시 휘발유가 환산 리터당 100원) 또는 `STORE`(이마트·롯데마트·홈플러스, GS25·CU, 커피/음료전문점, 약국 5%) 중 택1. 전월 실적 `40만~80만 미만 / 80만~120만 미만 / 120만 이상`에 월 한도 `1만 / 3만 / 5만원`. 신규 사용등록 후 다음 달 말까지 40만원 구간 유예, 선택 변경은 다음 달 1일부터 적용. 온라인 마트·SSM·입점매장·상품권 등의 예외가 있다. [상품설명서 1~2쪽](https://img2.kbcard.com/obj/card/download/09271__prdctOpmn_20240417.pdf)
- **실적과 기간:** 전월 1일~말일 일시불·할부 승인금액(해외는 전월 말까지 매입완료). 선택 할인 **받은 거래의 매출 전액**은 다음 실적 산정에서 제외. 월 할인한도는 매월 1일~말일 승인 기준, 이월 없음. 취소금액은 취소전표 접수월에 차감하며 할인한도 복원은 즉시 되지 않을 수 있다. 할인 자체는 무이자할부·상품권/선불카드 구입·충전 제외. [상품설명서 3~4쪽](https://img2.kbcard.com/obj/card/download/09271__prdctOpmn_20240417.pdf)
- **모델의 미확정 입력:** `FUEL`은 거래 시점 기준유가가 없으면 산정 불가. 선택 옵션과 변경 이력도 필요하다. 기본 적립과 선택 할인의 동일 거래 중복 적용·원 단위 처리 방식은 추가 공식 근거 확인 전까지 임의 확정하지 않는다. 공항라운지·발레파킹은 금전적 월간 결제 혜택이 아니므로 별도 범위 결정이 필요하다.

### 노리 체크카드 `01664`

- **생활혜택:** 전월 20만원 이상. CGV 35%(건당 1만~2만원), 아웃백·VIPS 20%(3만~5만원), 스타벅스 20%(1만~2만원), 에버랜드·롯데월드 50%(3만~5만원), GS25 5%(1만~2만원), 교보문고 5%(2만~5만원). 괄호의 상단은 할인 대상 이용금액 상한이며, 월 통합한도도 적용한다.
- **교통·통신:** 전월 30만원 이상. 시내버스·지하철 및 고속/시외버스 10%, 교통 월 이용금액 2만원까지(최대 2천원). 교통 할인은 실제 탑승일과 다른 카드사 이용내역서 기재일을 기준으로 할 수 있다. 지정 통신사(SKT·KT·LG U+) 요금을 해당 카드로 자동이체하고 **건당 5만원 이상**이면 2,500원 환급할인(월 1회). 유무선 통합청구금액은 제외한다. [상품설명서 1쪽](https://img2.kbcard.com/obj/card/download/01664__prdctOpmn_20260818.pdf)과 [KB 모바일 상품 상세의 ‘통신’ 혜택 팝업](https://m.kbcard.com/CXHIACRC0002.cms?mainCC=b&allianceCode=01664&jehuId=KBSTR&lstTyp=2&solicitorcode=2811042AAA&CINo=&bankSerno=&issueStateType=A)이 일치한다. 모바일 화면의 `건당 3만~5만원`은 **아웃백/VIPS 외식 할인**의 이용금액 구간이며 통신 조건이 아니다.
- **공통 월 통합한도:** 전월 20/30/50/100만원 이상에서 각각 1/2/3/5만원. 월 1일~말일, 이월 없음. 최초 사용등록일부터 60일간 전월 실적이 없으면 생활혜택에 1만원 한도를 제공하지만 교통·통신·금융수수료 면제는 제외.
- **실적·제외:** 전월 1일~말일 이용일 기준, 노리/락스타/해피노리/해피락스타 동일계열 합산. 후불교통, 해외, 무승인, 정부지원금, 취소금액 제외. 취소는 취소월 실적에서 차감. 상품권·입점 매장·매점 등 혜택별 제외는 [공식 상품 페이지](https://card.kbcard.com/CRD/DVIEW/HCAMCXPRICAC0076?mainCC=a&cooperationcode=01664)의 상세혜택을 따른다. 최근 1개월 합산 매입실적 70만원 조건의 은행 수수료 면제는 월간 결제 혜택과 별도 범위로 둔다.

## 3. CODEF 응답 → 내부 상태 매핑안

공식 명세: [KB 기관코드 `0301`](https://developer.codef.io/products/card/overview), [보유카드](https://developer.codef.io/products/card/common/p/account), [승인내역](https://developer.codef.io/products/card/common/p/approval), [실적조회](https://developer.codef.io/products/card/common/p/result-check). 데모 호출은 URL 디코딩 후 `result.code == CF-00000`을 확인한다. 아래는 **필드가 제공될 때의 후보 매핑**이며 KB가 모든 필드를 항상 반환한다는 뜻이 아니다.

| CODEF 입력 | 내부 후보 필드/용도 | 판정 한계 |
| --- | --- | --- |
| 보유카드 `resCardName`, `resCardType`, `resIssueDate`, `resTrafficYN`, `resState` | 보유카드 표시명·종류·발급/상태·교통기능 후보 | 상품코드·약관 버전이 없고 `RF`의 공식 SKU 의미도 확정되지 않는다. 표시명만으로 자동 `CONFIRMED` 금지. |
| 보유카드 `resCardNo`; 승인내역 `resCardNo`, `resCardNo1`, `resCardName`; 조회요청 `cardNo`, `cardName`, `duplicateCardIdx` | 조회 중 동일 카드 거래 연결 후보 | 응답마다 마스킹 여부/형식이 다를 수 있다. 전체 번호가 반환되면 앱 모델에 넣기 전에 제거하고 저장·로그·브라우저로 전달하지 않는다. 카드별 조회에 전체 번호가 필수라면 현재의 카드번호 비수집 원칙과 충돌하므로 구현 전에 보안 범위를 결정한다. 동명이 카드 충돌 시 사용자 확인하며 `duplicateCardIdx`를 영구 ID로 쓰지 않는다. |
| 승인내역 `resUsedDate`, `resUsedTime`, `resUsedAmount`, `resPaymentType`, `resInstallmentMonth`, `resCancelYN`, `resCancelAmount`, `resApprovalNo` | 실제 승인 거래·취소 후보 | 승인일/매입일/취소 접수일의 구분과 카드사 인정 실적을 승인내역만으로 확정하지 않는다. KB 취소전표매입은 음수 금액과 빈 취소금액으로 올 수 있다. 모의 거래 원장과 분리. |
| 승인내역 `resMemberStoreName`, `resMemberStoreType`, `resHomeForeignType`, `resCashBack` | 업종·국내외·환급액의 참고 단서 | 이름과 CODEF 업종을 KB 공식 혜택 업종코드로 동일시하지 않는다. 간편결제, 입점매장, 상품권, 자동납부 여부와 실제 월 할인잔액을 보장하지 않는다. |
| 실적조회 `resCardName`, 선택적 `resCardNo`·`resLnkUrl`, `resCardBenefitList`, `resCardPerformanceList`의 `resCurrentUseAmt`, `resRequiredPerformanceAmt`, `resMeetPerformanceYN`, `resCoverageCriteria`, `commStartDate`, `commEndDate` | 카드사 조회 실적·혜택 충족 상태를 **기간·출처·갱신시각과 함께** 저장하는 후보 | 자유문구/선택 필드는 약관 버전이나 혜택 월 잔여한도가 아니다. `resStandardUseAmt`를 다른 금액의 단순 합계로 추정하지 않는다. 룰 산정 기간과 다르면 사용자 확인 또는 `UNKNOWN`. |

**상태 정책 초안:** 상품 매핑은 `UNMAPPED → CANDIDATE → USER_CONFIRMED`로 나눈다. 실제 `올라운드 티타늄카드`에는 `09271`을, 실제 `nori 체크카드(RF)`에는 `01664`를 **공식 SKU 후보로만** 제시한다. 사용자가 표시명과 후불교통 기능은 확인했으므로 그 관찰만 `USER_CONFIRMED`로 기록할 수 있으나, 이것이 공식 SKU·약관 버전의 확인은 아니다. 매핑 확정에는 KB 공식 상품/설명서와 발급 시기의 세부 상품 확인이 추가로 필요하다. 사용자가 언급한 카드 유효기간은 공개 문서에 적지 않으며 발급일이나 혜택 규칙 적용 시작일로 해석하지 않는다. 가상 포트폴리오 네 장은 실제 CODEF 보유·이용내역과 별도의 `SYNTHETIC` 자료다. CODEF 실패·만료·매핑 모호 시 수동 상태 입력과 출처 표시를 유지한다.

## 4. 확인된 결정과 남은 미결 항목

1. **D-01 미결:** 사용자가 실제 카드의 표시명과 카드 뒷면 후불교통 표기를 확인했다. 다만 이것만으로 KB 상품 식별자 `09271`·`01664`와 해당 카드의 정확한 약관 버전을 확정하지 않는다. `RF`도 공식 일대일 식별자는 아니다.
2. **D-02 확정(2026-10-08):** 사용자가 시연용 신용 2종(올라운드 티타늄·청춘대로 톡톡), 체크 2종(노리·첵첵)을 선택했다. KB ALL은 이번 구성에서 제외한다. 티타늄 선택 서비스/기준유가 상태는 여전히 필요하다.
3. **D-03:** 선택 서비스 변경 이력, 주유 기준유가, 무승인 교통의 기준일, 톡톡 취소금액의 실적 차감 귀속월, 월 한도 소진·취소 복원 시점, 중복/원 미만 처리. 지원되지 않는 조건을 달력월·0원 혜택으로 임의 대체하지 않는다.
4. **D-04 미결:** CODEF 조회 실적과 실제 받은 혜택·잔여 월 한도의 관계, 업종/결제수단 판정에 필요한 데이터의 확보 여부.
5. **D-05 확정(2026-10-08):** 필수 상태가 불명확하면 사용자 확인을 요청하고 해당 혜택은 `확인 필요`로 표시해 확정 추천 계산에서 제외한다. 임의로 0원 또는 확정 금액으로 치환하지 않는다.
6. **평가:** 원문 조항과 연결한 독립 정답 사례 20개 및 입력 변경 시험 10개를 **엔진 구현 전에** 고정한다. 실제 개인 데이터가 아닌 합성 거래만 사용한다.
