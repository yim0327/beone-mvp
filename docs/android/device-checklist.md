# Android 실기기 확인 목록

사람이 실제 Android 기기에서 확인할 항목입니다. 단위 테스트, mock, 에뮬레이터 결과는 이 목록의 확인으로 인정하지 않습니다([PRD FR-06](../PRD.md), [D-08](../decisions.md#d-08-확정-정책)).

- 대상 기기: Samsung SM-S942N (Android 16, One UI 8.5), 지문 등록 + 화면 잠금 PIN (D-08)
- 설치: 사용자가 직접 `cd android && ./gradlew installDebug`로 설치합니다. 자동으로 기기에 설치·실행하지 않습니다.
- 실행: 런처의 **B:ONE 인증 점검** 아이콘(debug 빌드 전용)
- 기록: 결과를 PR 또는 이슈에 기기 모델·OS 버전·확인 날짜와 함께 적습니다. 생체·PIN 값이나 개인 정보가 보이는 화면은 첨부하지 않습니다.

## 기기 인증과 60초 활성 상태 (#22)

| # | 확인 항목 | 기대 결과 | 상태 |
| --- | --- | --- | --- |
| 1 | 점검 화면을 처음 연다 | 인증 창이 자동으로 뜬다 | 미확인 |
| 2 | 지문으로 인증한다 | `활성 중 (BIOMETRIC)`, 활성 표시 버튼 켜짐, 60초부터 줄어듦 | 미확인 |
| 3 | 그대로 60초를 기다린다 | 0초에 비활성화되고 만료·재인증 안내 | 미확인 |
| 4 | 인증 창에서 취소(뒤로 가기·바깥 터치) | 비활성, 취소 안내 | 미확인 |
| 5 | 활성 중 [기기 인증] → 취소 | 남은 시간과 관계없이 즉시 비활성 | 미확인 |
| 6 | 활성 중 재인증 성공 | 60초로 다시 시작(남은 시간이 더해지지 않음) | 미확인 |
| 7 | 등록하지 않은 손가락으로 불일치 → 잠김 → 같은 창에서 PIN | PIN 성공 시 `활성 중 (DEVICE_CREDENTIAL)` | 미확인 |
| 8 | 인증 창에서 PIN 전환 버튼으로 PIN 입력 | PIN 입력 중 인증 창이 닫히거나 `앱을 벗어나 비활성화`로 끊기지 않고, 성공 시 활성 | 미확인 |
| 9 | 활성 중 홈으로 나갔다가 복귀 | 즉시 비활성, `앱을 벗어나 비활성화` 안내 | 미확인 |
| 10 | 활성 중 최근 앱 화면으로 다른 앱 전환 후 복귀 | 9와 같음 | 미확인 |
| 11 | 활성 중 화면 회전 | 활성 유지, 남은 시간 이어짐(늘어나지 않음) | 미확인 |
| 12 | 활성 중 다크 모드 전환(빠른 설정) | 11과 같음. 빠른 설정 패널을 내리는 것만으로는 비활성화되지 않음 | 미확인 |
| 13 | 인증 창이 떠 있는 동안 화면 회전 후 인증 성공 | 결과가 유실되지 않고 활성화 | 미확인 |
| 14 | [기기 인증]을 빠르게 여러 번 누름 | 인증 창이 하나만 뜸 | 미확인 |
| 15 | 인증 창이 떠 있는 동안 홈으로 나갔다 복귀 | 인증 창이 닫혀 있고 활성화되지 않음, `앱을 벗어나 비활성화` 안내. [기기 인증]으로 다시 인증 가능 | 미확인 |

## D-08 남은 검증 (FR-06 실기기 검증)

| # | 확인 항목 | 기대 결과 | 상태 |
| --- | --- | --- | --- |
| 16 | 지문을 모두 삭제하고 화면 잠금 PIN만 남긴 상태(PRD §4.3-2) | 인증 창에서 PIN으로 진행, 성공 시 활성 | 미확인 |
| 17 | 화면 잠금을 해제한 상태(PRD §4.3-5) | 인증 창 없이 설정 필요 안내, 활성화하지 않음 | 미확인 |

16·17은 기기 보안 설정을 바꿔야 하므로 기기 소유자가 직접 판단해 진행하고, 끝나면 D-08 설정(지문 + PIN)으로 되돌립니다.

## 이 목록 밖의 항목

- WebView 화면 표시와 웹으로 상태 전달: 아직 구현하지 않았습니다(로딩 방식·신뢰 origin·브리지 계약 미확정).
- 실제 `가상 주문서 결제` 버튼과 모의 승인 흐름: React 화면·브리지 연결 뒤 확인합니다.
